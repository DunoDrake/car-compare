# CarCompare

Website so sánh ô tô theo phiên bản, giữa các hãng và theo tầm giá. HTML, CSS, JS thuần, không cần build.

- Dữ liệu từng hãng: `data/<hãng>.js`
- Ưu/nhược điểm: `data/reviews.js`
- Giá động: đặt link CSV của Google Sheet vào `data/config.js` (mẫu bảng giá: `data/prices-template.csv`)

Giá và thông số mang tính tham khảo, vui lòng xác nhận lại với đại lý trước khi mua.
